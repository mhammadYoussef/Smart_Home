# Changelog

## Unreleased — Smart Home

Rebranded the interface to Smart Home. Added English/Arabic switching with right-to-left layout and a saved language preference (`public/i18n.js`). Fonts are the original system stacks; Arabic uses the system Arabic font. Charts now draw at their container's size, the mobile header wraps, and touch screens get 44px controls. The sidebar can be expanded, collapsed to an icon rail or hidden, and becomes a slide-out drawer on phones; these choices are saved. New project README. Redesigned dark theme and new light theme built on CSS design tokens, with a saved sun/moon toggle that defaults to the system preference; theme-aware charts and house illustration. Removed the header status badge. The sidebar side now follows the language (left in English, right in Arabic); the manual left/right control and its saved setting were removed.

## 1.0.0 — 2026-10-26

Initial free starter: synthetic offline demo, generic home illustration, home/heat-pump/history views, JSON import/export, optional local recorder, HomeyScript export template, customization and connection guides. No personal build data or device configuration included.
